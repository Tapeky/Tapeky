### About

- 🛠️ Most of my public work comes from the **42 curriculum**: C, C++, networking, graphics, and DevOps — no frameworks, no shortcuts.
- 🌐 Lately I've been moving up the stack: **TypeScript**, **Next.js / NestJS**, **PostgreSQL**, **Docker**, **Flutter**.
- 🔐 I like the unglamorous parts — parsing, error handling, reverse proxies, secrets management, and tests that actually fail.
- 📚 Currently exploring **linear algebra & boolean logic** through the 42 outer-core projects.
